# Clink 中文九键

给 [Clink: Custom Keyboards](https://github.com/anti-ltd/clink-index) 用的**九宫格拼音输入面板**。

点 `ABC` 不会打出字母，而是参与拼音消歧并出候选词 —— 和 iOS 九宫格一样。

## 安装与使用

1. Clink → **General → Repositories**，添加：

   ```
   dayifulalala-del/clink-layout-zh9
   ```

2. 回到 Clink 主界面，点**底部导航栏的「工具」**（不是设置里的 Tools，是最下面那一排标签：主页 / 工具 / 插件 / 搜索）。
3. 在里面找「自定义面板 / Custom Panels」，选中本仓库，下载「**中文九键 T9**」。
4. 面板含可执行逻辑，Clink 会单独要求一次信任授权。

## 界面

```
┌─────────────────────────────────────────────┐
│  普通  如同  去  如  区  入  取      ← 候选词  │
├──────┬────────┬────────┬────────┬──────────┤
│  pu  │  '词   │  ABC   │  DEF   │    ⌫     │
│  qu  ├────────┼────────┼────────┼──────────┤
│  ru  │  GHI   │  JKL   │  MNO   │   重输    │
│  su  ├────────┼────────┼────────┼──────────┤
│  su  │  PQRS  │  TUV   │  WXYZ  │   确定    │
├──────┼────────┴───┬────┴────┬───┴──────────┤
│ 音节 │ 符号  123  │  空格   │    中 / 英    │
└──────┴────────────┴─────────┴──────────────┘
```

- **3×3 主网格** —— ITU E.161 标准分组，点一下只累积按键，**不插入字母**
- **候选词栏** —— 按词频排序，整句用最长匹配组合
- **左侧音节列** —— 按 `PQRS`+`TUV` 列出 `pu / qu / ru / su`，点选锁定读音、候选收窄到单字
- **`'词`** 分词 · **`⌫`** 退格 · **`重输`** 清空 · **`确定`** 上屏 · **`空格`** 选首候选
- **`中 / 英`** —— 英文为传统多击：连按同键 `a→b→c` 循环，换键确认
- **`符号` / `123`** —— 中文标点与数字页

## 词典

三个 MIT 数据集合成，完全离线内嵌，8,265 个按键序列，覆盖 87.6% 词频：

| 来源 | 用途 |
|---|---|
| [pinyin-data](https://github.com/mozillazg/pinyin-data) | 单字 → 拼音 |
| [phrase-pinyin-data](https://github.com/mozillazg/phrase-pinyin-data) | 词语 → 拼音（处理多音字） |
| [jieba](https://github.com/fxsjy/jieba) | 词频 → 候选排序 |

署名见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 为什么是面板，不是布局

`Layouts/` 下保留着两个布局文件，但**不随 release 发布**，因为它们做不到九宫格输入。实测确认的 Clink 布局格式行为：

| 行为 | 实测结果 |
|---|---|
| 四行布局 / 数字键标 / `globe`·`backspace` 功能键 | ✅ 接受（上游文档说"恰好三行小写字母"，那是投稿规范，不是引擎限制） |
| 行结构 | ✅ 决定渲染形状，每行三键 → 渲染成 3 列九宫格方块 |
| 多字母键标 `abc` | ❌ **原样插入字面字符串 "abc"**，不做九宫格展开 |

也就是说：**布局能做出九宫格的形状，但做不出九宫格的输入逻辑。** Clink 的中文转换来自语言包 `zh.cime` 的精确读音查表（`zhong` → 中），不接收歧义按键。

面板是 Clink 里唯一能自绘网格、自行累积按键序列并输出候选词的机制，所以九宫格输入只能做成面板。

一份 release manifest 只能声明一种资源类型，所以发布面板时布局不会出现在「布局 → 排列」里。要切回发布布局，把工作流改成扫描 `Layouts/` 并生成 `layouts` 键即可。

## 开发

```bash
python3 tools/build-panel.py      # 重建词典与面板（首次下载约 7 MB 源数据）
python3 tools/test-panel.py       # 执行面板逻辑，模拟打字验证（33 项断言）
python3 tools/build-manifest.py   # 重建 manifest.json
```

CI 在发布前会跑 `test-panel.py`。
