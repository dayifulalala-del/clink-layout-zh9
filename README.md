# Clink 中文九键布局

Chinese T9 Pinyin style layout for Clink Keyboard.

## Features

- iOS 风格九宫格布局
- 适合中文拼音九键输入
- 保留 Clink 原生输入逻辑
- 简洁单手输入设计

## Layout

```
┌────┬────┬────┐
│ 1  │ABC │DEF │
├────┼────┼────┤
│GHI │JKL │MNO │
├────┼────┼────┤
│PQRS│TUV │WXYZ│
└────┴────┴────┘
```

## Install

Add this repository to Clink community layouts:

```
dayifulalala-del/clink-layout-zh9
```

## Note

This project provides the keyboard layout only. Chinese candidate processing depends on Clink's input engine.
