# Clink 中文九键布局

给 [Clink: Custom Keyboards](https://github.com/anti-ltd/clink-index) 用的中文九宫格布局。

安装后在 Clink 的 **布局 → 排列** 里，选中本仓库这个来源即可看到。

## 包含的布局

### 中文九键 Chinese T9

```
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
├─────┼─────┼─────┤
│  7  │  8  │  9  │
├─────┼─────┼─────┤
│ 🌐  │  0  │  ⌫  │
└─────┴─────┴─────┘
```

四行三列，Clink 会按这个行结构渲染成真正的九宫格方块。

**已知限制：按键输出的是数字，不是拼音。** 详见下方「关于九宫格中文输入」。

### 拼音方格（测试）Grid Pinyin test

26 个字母按字母序排成方格，每键一个字母：

```
a  b  c  d  e  f
g  h  i  j  k  l
m  n  o  p  q  r
s  t  u  v  w  x
🌐 y  z  '  ⌫
```

这是一个**实验布局**，用来验证：方格形状 + 单字母键，能否正常驱动 Clink 的拼音引擎打出中文。如果可以，说明方格形状的中文键盘是可行的；如果不行，说明布局这条路对中文输入完全不通。

## 关于 Clink 布局格式的实测结论

官方 `PROMPT.md` / `VERIFY.md` 要求「恰好三行小写键标」。**那是官方仓库的投稿规范，不是引擎的能力边界。** 实测确认：

| 行为 | 实测结果 |
|---|---|
| 四行布局 | ✅ 接受 |
| 数字作键标 | ✅ 接受 |
| `globe` / `backspace` 等功能键名 | ✅ 接受 |
| 行结构决定渲染形状 | ✅ 每行三键 → 渲染成 3 列方格 |
| 多字母键标（如 `abc`） | ⚠️ **原样插入字面字符串 "abc"**，不做九宫格展开 |

## 关于九宫格中文输入

Clink 的中文转换来自**语言包**：`zh.cime` 提供「读音 → 汉字」的**精确查表**（`zhong` → 中）。使用前需在 Clink → **Languages** 安装 🇨🇳 Chinese。

九宫格需要的是「一个键代表 abc 三种可能」的**歧义展开**，这是另一套算法。布局文件里没有任何 T9 分组机制，多字母键标也只会被原样插入。

所以：**形状可以做出来，输入逻辑做不出来。** 这是 Clink 当前的机制限制。

## 未发布的内容

`Panels/` 和 `tools/` 下有一个完整的 T9 拼音输入面板（`.clinkpanel`），自带 3×3 网格、词频候选与音节消歧，逻辑经 33 项测试验证。它**当前不随 release 发布**，因为面板属于 Clink 的「工具箱」（底部导航 → 工具），不是日常键盘，且一份 release manifest 只能声明一种类型。

需要启用时，把发布工作流切回 `tools/build-manifest.py`（生成 `panels` 键）即可。

## 安装

1. Clink → **General → Repositories**，添加：

   ```
   dayifulalala-del/clink-layout-zh9
   ```

2. Clink → **布局 → 排列**，选中本仓库来源，下载需要的布局。
